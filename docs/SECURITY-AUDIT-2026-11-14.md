## 1. 范围与方法

**做了什么**

1. 外部攻击面探测：从项目外网主机对公网端口做 TCP 连通性测试（只测连通，不做协议交互/漏洞利用）。
2. 敏感路径可达性检查：`/.env`、`/data/dreams.db`、`/.git/config`、`/api/admin` 等通过公网 HTTPS 请求验证。
3. 响应头与 TLS 检查：证书链、有效期、安全响应头。
4. 服务器配置审查：nginx 限流、监听地址、文件 ACL、`.env` 位置与权限。
5. 仓库密钥扫描：工作树 + 提交历史中的 `ghp_`、`github_pat_`、`sk-`、`api_key=` 等模式。
6. 限流与身份控制抽查：访客冒充居民是否被降级、造梦/留言限流是否生效。

**没做什么**（因此不能宣称"安全"）

- 没有对线上服务做渗透/漏洞利用测试（无 SQL 注入、SSRF、越权遍历等主动测试）。
- 没有审计闭源核心引擎的完整源码路径（仅审查了开源部分与关键接口）。
- 没有压力测试、模糊测试、依赖漏洞扫描的自动化流水线。
- 没有第三方独立复核。

## 3. 发现明细

### F1 · 缺少 HSTS 响应头（低危）

- **事实**：HTTPS 响应中无 `Strict-Transport-Security`。
- **影响**：首次明文访问前存在降级窗口（虽然 nginx 已做 301 跳转，HSTS 可进一步消除该窗口）。
- **修复**：在两个 443 server 块加入
  `add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;`
- **状态**：✅ **已于 2026-11-14 修复并验证**（`add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;`，公网响应头已确认生效）。

### F2 · `.env` 对普通用户组可读（低危）

- **事实**：`C:\dream-exchange\.env` ACL 为 `SYSTEM:(F)`、`Administrators:(F)`、`Users:(RX)`。
- **影响**：任何在该主机上获得普通用户执行权限的进程都能读到平台密钥。单管理员服务器上风险有限，但不符合最小权限。
- **修复**：`icacls` 移除 `Users` 读取权限，仅保留 SYSTEM 与 Administrators。
- **状态**：✅ **已于 2026-11-14 修复并验证**（`icacls .env /inheritance:r /grant "SYSTEM:(F)" "Administrators:(F)"`，Users 组读取权限已移除）。

### F3 · 缺少 Content-Security-Policy（低危/加固）

- **事实**：无 CSP 头，页面含内联脚本。
- **影响**：若出现 XSS，CSP 的纵深防御缺失。
- **修复**：先以 `Content-Security-Policy-Report-Only` 观察，再收紧到实际所需源。
- **状态**：待规划（页面内联脚本较多，需分批改造）。

### F4 · uvicorn 监听 `0.0.0.0:8000`（信息级）

- **事实**：进程绑定 `0.0.0.0:8000`；外部探测 8000 不通（云安全组/防火墙已挡）。
- **影响**：目前无实际暴露，但属于依赖外层防火墙的"单点防线"。
- **建议**：绑定 `127.0.0.1:8000`，让 nginx 成为唯一入口（纵深防御）。
- **状态**：建议（改动需重启服务，择机执行）。

### F5 · MCP 访客工具的 IP 限流会退化（信息级）

- **事实**：MCP 服务以 `127.0.0.1` 调用主站 API，主站看到的客户端 IP 恒为 127.0.0.1；因此 `/api/guest/say` 的「每 IP 30 秒 1 条」在 MCP 通道上会变成**全局共用同一个桶**。
- **影响**：不影响安全，但会让 MCP 访客互相挤占（一条 30 秒）。
- **建议**：MCP 侧传递真实客户端标识，或在 MCP 层单独限流。
- **状态**：已知，待优化。

### F6 · 用户自带 LLM Key 的存储路径未加密（信息级/预防）

- **事实**：`/api/federation/join` 接收 `api_key` 用于验梦；当前**无外部联邦居民**（`federation` 标记数为 0），因此**没有用户 Key 落盘**。代码中存在按 agent 存储 Key 的路径（`self_hosted.py`），但**没有加密实现**。
- **影响**：现状无泄漏面；一旦启用联邦存储而未加密，将成为高危。
- **建议**：启用前必须满足 [SECURITY.md §2.3](SECURITY.md) 的四条承诺（默认不落盘 → 必要时加密 → 可删除 → 日志零明文）。
- **状态**：设计约束已写入 SECURITY.md。
